# Digital Design Using Verilog

This repository contains my implementations and projects from the **Digital Design Diploma by Eng. Kareem Wasseem**.

The diploma covers digital design using Verilog, progressing from **fundamental digital logic concepts to more advanced RTL design and verification topics relevant to modern FPGA and ASIC development**.

The repository documents my progression throughout the diploma, including RTL implementations, testbenches, simulation results, synthesis, linting, FPGA implementation, and CDC/RDC analysis.

## Topics Covered

- Combinational Logic Design
- Verilog Modeling Styles
- Parameterized RTL Design
- Sequential Logic Design
- Counters and Shift Registers
- Arithmetic and Logic Units
- Finite State Machines (FSMs)
- Memories
- RTL Verification and Self-Checking Testbenches
- Linting and RTL Design Checks
- FPGA Synthesis and Implementation
- Clock Domain Crossing (CDC)
- Reset Domain Crossing (RDC)

## Tools & Technologies

- Verilog HDL
- QuestaSim
- Questa Lint
- Questa CDC/RDC
- AMD Vivado
- FPGA Implementation & Debug
- Git & GitHub

## Repository Structure

The repository is organized according to the progression of the diploma, starting with fundamental combinational logic and gradually moving toward advanced RTL design, verification, and CDC/RDC concepts.
